Secure SQL Agent: try to break it

A text-to-SQL agent over synthetic bank data. Every query runs as the person asking, so Postgres (roles, column grants, row level security) decides what comes back. Not the model.

Mode

1. Pick who you are

2. Ask something (or try to break it)

then

3. Skip the AI entirely

Run a fixed, reviewed SQL statement straight against Postgres as the chosen role: no model, no SQL validator. Even a fully fooled model can't see more than this. (Visitors can't send their own SQL.)

Synthetic data only; the 7 identities are demo staff accounts. Source, eval numbers and design notes: github.com/iamr1ddl3/secure-sql-agent
